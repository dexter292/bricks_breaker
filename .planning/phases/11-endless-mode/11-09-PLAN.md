<objective>
Close 11-VERIFICATION.md gaps 2 and 3: make a failed endless start **atomic** and give it a
**surface**.

The verifier's reframing, which this plan adopts as its frame: the three remaining defects are
data **LOSS**, not record inflation. None can raise `telemetry.endless.bestWave`. What they do is
silently discard the deep run the record exists to capture, or silently do nothing at all where
the owner decided something visible must happen. `no run is lost` is the standard this round is
measured against, not `no run is inflated` — that one is already closed and stays closed.

Gaps 2 and 3 have one shared resolution and this plan exploits it rather than solving them twice.
`startEndlessRun` currently performs two irreversible writes above its failure return
(`runSeedRef.current = Date.now() >>> 0` at 1115 and `waveRef.current = 1` at 1116), and both of
its failure returns set the failure copy while `modeRef` / `mode` are still `'campaign'` and
`result` is still `null` — so `ResultOverlay.tsx:105` nulls the prop and `GameScreen.tsx:117`
never mounts the overlay. Forcing the Results overlay up on a failed start gives gap 3's copy a
surface on every entry path AND resolves gap 2's `ended but did not restart` state at once.

Purpose: a player who presses the only control that enters endless must never be met with nothing,
and a run must never end up half-started.
Output: a `failEndlessStart()` helper both failure returns route through, an atomic seed
attempt, a named Retry-time/mid-run discriminant, and — most importantly — behaviour tests that
drive the real host and the real overlay and assert on **rendered output**, because a
source-contract test proving the write and never the render is exactly what let gap 3 ship.
</objective>
