## stepWorld algorithm (RESEARCH diagram)
1. Clear brickDamagedThisStep
2. If Number.isFinite(intent.paddleX): clamp paddleX to field; else keep prior (T-02-01)
3. For each active ball i in index order:
   remaining = dt (must be FIXED_DT from callers)
   loop ≤ MAX_CCD_ITERATIONS:
     earliest = min TOI among walls, paddle, broadphase bricks
     if miss → advanceBall(remaining); break
     advanceBall(toi*remaining); resolve; pushEvent; apply brick HP if breakable & !damagedThisStep; remaining -= toi
4. Bounds backstop (clamp center inside field expanded by radius)
5. tick++
