<objective>
Scale the tracer's end-to-end proof to the sweep SC-2 actually demands, and pin determinism to
constants that break loudly.

**Decision recorded here, not deferred — validation task 10-02-04 (the `.mjs` CI twin).**
`scripts/assert-generated-solvability.mjs` is **not** created. R-16's requirement is that both
implementations of the lint agree on the same artefacts, and
`tests/levels.solvability-parity.test.ts:10-25` already proves a `.ts` test can import
`scripts/lib/levelSolvability.mjs` directly — so both implementations can see the generated
corpus **in-process, from the live `generate`**, with no checked-in fixture. A standalone `.mjs`
script cannot import TypeScript (the `scripts/lib/*.mjs` header rule, and Node's ESM resolver
rejects this repo's extensionless relative imports under type-stripping), so it would need
either a second `generate` written in ESM — a third algorithm requiring a third parity test,
which RESEARCH's "Don't Hand-Roll" table explicitly warns against — or a checked-in board
corpus that goes stale the instant Phase 11 re-tunes `SCHEDULE` and whose staleness would itself
need a guard. Both costs exceed the marginal value, and `npm test` runs `vitest run` first, so
the gate stays in the full-suite chain either way. `10-VALIDATION.md` task 10-02-04 is updated to
`npx vitest run tests/levelgen.sweep.test.ts -t 'R-16'`.

Purpose: make N-GEN-02 a swept property rather than a sample, and make any accidental change to
the PRNG, the candidate ordering or the schedule flip exactly one hex string.
Output: the full sweep, the engine-portable corpus fingerprint, and both pinned digests.
</objective>
