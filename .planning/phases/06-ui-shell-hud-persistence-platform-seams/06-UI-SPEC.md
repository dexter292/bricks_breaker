# Phase 6 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Stack note:** React Native / Expo + Skia immediate-mode game UI — **not** a web component-library app. No shadcn, Tailwind, or CSS framework. Design tokens apply to thin React Native shell / HUD / overlays. Playfield remains Skia (unchanged visual language from Phase 3–5).
>

## Spacing Scale

Declared values (must be multiples of 4). Used for **React shell chrome** (Title, HUD strip, Pause / Results / Menu actions), not for virtual playfield physics units.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | HUD metric gaps, inline badge padding |
| sm | 8px | Compact strip inner padding; button stack gaps for secondary actions |
| md | 16px | Default overlay / strip horizontal padding; button horizontal padding |
| lg | 24px | Overlay panel inner padding; Title content column padding |
| xl | 32px | Stack gap between overlay title block and primary CTA |
| 2xl | 48px | Safe clearance above home-indicator for bottom-ish CTAs on Title / Results |
| 3xl | 64px | Title brand → Play vertical rhythm; top chrome under notch when strip not used |

**Exceptions:**

| Exception | Value | Reason |
|-----------|-------|--------|
| Touch target minimum | 44×44 px | Play, Pause, Resume, Retry, Menu — iOS HIG / Android 48dp-adjacent floor (44 logical px min; prefer 48 where layout allows) |
| HUD strip height | 48px content row (+ safe-area top inset) | Compact single row; must not cover playfield brick bands |
| Countdown numeral | Display 48px, centered | Inherited from Phase 3 — not spacing-token driven |
| Logical playfield | 360×640 vu | Letterbox preserved (D-14); bars `#000000` |

**Safe-area / letterbox (D-14, D-15, PLT-02):**

- Playfield: fixed 360∶640 aspect, scaled uniformly into the **safe-area** box; letterbox/pillarbox `#000000`.
- HUD strip, Title, Pause, Results, Countdown: layout **inside** `useSafeAreaInsets` — never under notch / Dynamic Island / home indicator.
- HUD strip sits in the top inset band (semi-transparent) **above** the letterboxed field; it must not draw opaque chrome over brick rows.

## Color

60 / 30 / 10 for **app shell + play composition**. Flat solids only — **no neon, glow, blur, particles, trails** (deferred Phase 7).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#1a1a2e` | Playfield fill (unchanged); Title full-screen field behind content |
| Secondary (30%) | `#000000` + scrim `#000000` @ 60%; panel `#12121f`; HUD strip `#12121f` @ 80% opacity | Letterbox; overlay dimmers; Title/Pause/Results panels; compact HUD strip backing |
| Accent (10%) | `#FFFFFF` | Ball/paddle (unchanged); primary CTA fills; primary CTA labels on dark; Title Display name; HUD metric text; countdown numerals |
| Destructive | `#E85D5D` | Lose overlay title only |
| Record highlight | `#F2CC8F` | **New Record** badge fill only (flat; already in Phase 3 brick HP-1 family — not a glow) |

Accent reserved for:

1. Ball / paddle silhouettes (unchanged)
2. Primary CTA fill (`#FFFFFF` button + `#1a1a2e` label): **Play**, **Resume**, **Retry**
3. Title Display product name
4. HUD strip metric text and Pause outline control
5. Countdown Display numerals

**Never use accent for:** brick fills, letterbox, pause scrim, decorative borders as ornament, ads/IAP/login chrome (forbidden this phase), or Phase 1 cliff-ramp cyan (`#00ffaa`) outside `__DEV__` perf overlay.

**Secondary CTA (Menu):** outline style — panel/transparent fill, `1px` `#FFFFFF` border, `#FFFFFF` Label text on `#12121f` — **not** filled accent (keeps Retry/Play visually dominant per D-04 / D-11).

**Source:** `03-UI-SPEC.md` Color; CONTEXT D-06, D-11, D-18; Claude discretion for strip opacity + New Record badge.

## Interaction Contract

### App shell navigation (D-01…D-05, RUN-03)

```
Cold start → Title
Title → Play → load level (existing pipeline) → Playing (docked serve)
Playing → Pause → Paused overlay
Paused → Resume → Countdown 3·2·1 → Playing
Paused → Retry → reset run → Playing (instant, no confirm)
Paused → Menu → Title (refresh Best from storage)
Playing → Win | Lose → Results
Results → Retry → reset run → Playing (instant, no confirm)
Results → Menu → Title (refresh Best from storage)
OS background → auto-pause + accumulator reset → Paused (never auto-resume)
```

- Cold start **must not** land in Playing (D-02).
- Preserve Phase 3 pause/OS rules (D-05): AppState auto-pause, accumulator reset, Resume then 3s countdown.
- Menu is React `Pressable` only — never a playfield tap.
- Retry remains instant with no confirmation dialog.

### HUD strip (D-06…D-09, SC-2)

| Rule | Contract |
|------|----------|
| Placement | Compact **top** strip inside safe-area; full width of safe content; semi-transparent Secondary backing |
| Contents | Score · Combo · Lives on the leading side; **Pause** trailing while `uiPhase === playing` and no result |
| Stall | Append / show **Stall! · N** only when gated (PLAYING + tier > 0); hide when docked / paused / countdown / results |
| Obstruction | No center-screen HUD; no opaque full-width bars covering brick rows |
| Data path | **SharedValue mirrors only** + `useAnimatedReaction` → discrete React text updates — **never** per-physics-frame `setState` (D-08) |
| z-order | Chrome above opaque Skia canvas (existing `GameScreen` pattern); strip `pointerEvents` allows Pause only |

### Results & persistence display (D-10…D-13, RUN-04)

- End of **every** run (Win **or** Lose): compare run score to stored best; if greater, update best **asynchronously** (non-blocking).
- Results always show run **Score** and current **Best** (post-compare value for display: if new record, Best equals this run’s score).
- **New Record** badge only when this run set a new best.
- Title refreshes Best when entering Title (including Menu return).
- Persistence must not touch the sim/render hot path or introduce per-frame React writes.

### Layout (D-14…D-16, PLT-02)

- Keep letterboxing; do not stretch the virtual field.
- Centered overlay panels (`minWidth` 200, `maxWidth` 320) with ≥44 touch targets — same spirit as Phase 3.
- Usable across target phone range (notched iPhone + Android).

### Monetization / account seams (D-17…D-19, ARCH-02)

- **Code-only** interfaces + no-op stubs with real call sites (e.g. `onRunEnded`).
- **Forbidden UI:** no ad banners/interstitials, no shop, no rewarded-continue button, no sign-in / account screens, no “watch ad” copy, no IAP price labels.
- Airplane mode: full play loop + Title/HUD/Results/Best must work with zero network.

### Playfield gestures

Inherited verbatim from `03-UI-SPEC.md` Interaction Contract (relative pan, docked tap serve, overlay ownership while paused/countdown/results). Phase 6 does not change gesture semantics.

## Screen Layouts (normative)

### Title

```
[ safe-area ]
     Neon Brick Breaker     ← Display, accent
     Best · {n}             ← Body
           [ Play ]         ← Primary filled CTA
[ safe-area bottom ]
```

Dominant navy full bleed; optional subtle Secondary panel behind CTAs — **no cards cluster**, no stats row beyond Best, no ad placeholders.

### Playing (HUD)

```
[ safe-area top | strip bg 80% ]
  Score · N   ×C   Lives · L    [Stall! · T?]     [Pause]
[ /strip ]
[ letterboxed playfield … ]
[ Tap to launch — docked only ]
```

### Pause

Scrim 60% → panel: **Paused** / Resume / Retry / Menu (Menu last, outline).

### Results

Scrim 60% → panel: **Win|Lose** / body / Score / Best / [New Record] / **Retry** (filled, first) / **Menu** (outline, second).
