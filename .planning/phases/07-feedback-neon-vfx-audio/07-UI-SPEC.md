## Spacing Scale

Declared values (must be multiples of 4). Used for **React shell chrome** continuity and **VFX layer padding / bake margins** — not for physics world units.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Glow bake halo inset pad around brick fill; spark radius floor |
| sm | 8px | Compact shell gaps (unchanged); max glow halo extension beyond brick edge at full intensity |
| md | 16px | Default shell padding (unchanged) |
| lg | 24px | Overlay panel padding (unchanged) |
| xl | 32px | Shell stack gaps (unchanged) |
| 2xl | 48px | Shell safe clearances (unchanged) |
| 3xl | 64px | Shell title rhythm (unchanged) |

**Exceptions:**

| Exception | Value | Reason |
|-----------|-------|--------|
| Trail history length | 2–5 samples (frames), not px | FX-01 afterimage ring — intensity-mapped; never 0 |
| Particle lifetime | 120–220 ms | Cosmetic spark feel band (research / Claude discretion) |
| Destroy flash duration | ≤100 ms | Must not hide ball long enough to cost a rally |
| Shake amplitude | ≤2.5 logical playfield px | Subtle cosmetic camera offset only |
| Glow bake variants | 2 radius sizes max | Soft idle halo + slightly stronger destroy-adjacent bake — never live BlurMask |
| Touch targets | 44×44 px | Inherited shell controls only — no new Phase 7 controls |

**Picture / draw layering (Game Token Priority — locked):**

```
1. Letterbox / field navy fill
2. Idle brick fills + baked neon edge/halo (under fill or as under-blit)
3. Brick damage cues (cracks / hatch — Phase 4)
4. Destruction particles + brief destroy flash
5. Pickup sprites (flat amber — Phase 5)
6. Paddle
7. Ball trail ghosts (oldest → newest, under current ball)
8. Ball (current position — highest contrast token)
9. Cosmetic camera shake = translate on the letterboxed playfield group only (never World coords)
```

Particles and flash **must draw under paddle and ball**. Trail ghosts draw **under** the live ball silhouette so the current ball stays distinguishable.

**Source:** CONTEXT D-02, D-09, D-19; RESEARCH Patterns 2–5; FEATURES Game Token Priority.

## Color

60 / 30 / 10 for **playfield + neon spectacle** on the existing navy field. Shell chrome colors unchanged from Phase 6.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#1a1a2e` | Playfield background — navy remains the canvas for neon contrast |
| Secondary (30%) | `#000000` letterbox; brick fills `#C44569` / `#E07A5F` / `#F2CC8F` / `#6B7280`; baked glow derived from brick fills | Letterbox; brick bodies; idle neon halo tints inherit brick color |
| Accent (10%) | `#FFFFFF` + cyan rim `#67E8F9` | Ball / paddle silhouettes; trail cores; particle white/cyan highlight flecks; destroy flash peak |
| Destructive | `#E85D5D` | Lose overlay title only (shell — unchanged); **not** used as particle color |
| Neon highlight | `#67E8F9` | Trail rim stroke; particle highlight flecks; optional glow edge boost — **gameplay neon only**, never Phase 1 cliff `#00ffaa` |

**Brick → particle inheritance (D-08):**

| Source | Particle body | Highlight flecks |
|--------|---------------|------------------|
| HP3 `#C44569` | same | `#FFFFFF` / `#67E8F9` |
| HP2 `#E07A5F` | same | `#FFFFFF` / `#67E8F9` |
| HP1 `#F2CC8F` | same | `#FFFFFF` / `#67E8F9` |
| Unbreakable | no destroy burst (reflect only) | — |

Accent reserved for:

1. Ball silhouette (must remain highest-contrast object)
2. Paddle silhouette
3. Trail ghost cores (white/light) + cyan rim on newest ghost at high intensity only
4. Particle white/cyan highlight flecks (not full particle body)
5. Brief destroy glow flash peak (additive / high alpha, ≤100 ms)
6. Shell primary CTAs / HUD text (unchanged Phase 6 — not recolored this phase)

**Never use accent cyan for:** idle brick fills replacing the HP palette, letterbox, HUD chrome, or unbounded full-screen bloom lasting >100 ms.

**Idle glow (D-05):** Soft neon edge/halo **baked into `SkImage`** per brick color (≤2 radius variants). Halo alpha at intensity 1.0 ≈ 0.35–0.55 at edge falloff; at intensity 0.2 ≈ 0.15–0.25. **Forbidden:** per-brick live `BlurMask` / image-filter blur every frame.

**Source:** `src/render/colors.ts`; CONTEXT D-01, D-05, D-08, D-12; RESEARCH Pattern 3; Claude discretion for cyan hex `#67E8F9` (readable on navy, distinct from cliff `#00ffaa`).

## VFX Visual Contracts

### Global intensity scalar (D-03, FX-02)

| OS reduce-motion | `vfxIntensity` | Visual outcome |
|------------------|----------------|----------------|
| Off (default) | `1.0` | Full trail (5 ghosts), full particle spawn, glow at bake strength, shake at feel band |
| On | `0.2` | Dampened — trail **never off**; shake ≈ 0; particles/glow/flash scaled down |

**Mapping rules (all emitters multiply by scalar):**

| Effect | Intensity `1.0` | Intensity `0.2` | Hard floor |
|--------|-----------------|-----------------|------------|
| Trail length | 5 afterimages | 2 afterimages | **≥2** — never 0 / never “effects off” for trail |
| Trail glow/bloom | subtle cyan rim on newest ghost | **no** glow/bloom — high-contrast flat ghosts only | — |
| Chip sparks | 4 | `round(4 × 0.2)` → 1 | ≥0 (chip may be near-invisible; trail still on) |
| Destroy sparks | 12 | `round(12 × 0.2)` → 2 | — |
| Destroy flash alpha | peak ≤0.45 | peak ≤0.12 | duration still ≤100 ms |
| Idle glow alpha | bake × 1.0 | bake × 0.2 | glow may be very soft; bricks stay readable via flat fill |
| Shake amplitude | full band (see below) | approaches **0** | — |

Intensity is a single SharedValue from `AccessibilityInfo` (live `reduceMotionChanged`). No in-game settings UI.

### Ball trail — FX-01 (D-10…D-14)

| Property | Contract |
|----------|----------|
| Style | Fading **ghost afterimages** (discrete circles) — **not** a continuous ribbon Path |
| History @ 1.0 | **5** frame samples per ball |
| History @ ≤0.25 | **2** high-contrast samples |
| Color | Core `#FFFFFF` (match ball) @ alpha ramp oldest→newest ≈ 0.15 → 0.55; cyan rim `#67E8F9` stroke on **newest ghost only** when intensity ≥ 0.75 |
| Size | Ghost radius = ball radius; no oversized blooms |
| Multi-ball | Bounded ring **per ball slot**; same rules independently |
| Readability rule | Current ball fill always drawn **after** ghosts and at full `#FFFFFF` opacity — player must distinguish live ball at max speed |
| Implementation | SharedValue / typed-array history only — **no** per-frame React state |

### Neon glow & particles — FX-02 (D-05…D-09)

| Property | Contract |
|----------|----------|
| Idle bricks | Always-on soft neon edge via **baked/cached** sprites — blit under/around fill |
| Chip (`BRICK_HIT`) | Same language, small: **4** sparks @ 1.0; life **120–160 ms**; no shake; no flash |
| Destroy (`BRICK_BREAK`) | Larger: **12** sparks @ 1.0; life **160–220 ms**; + **brief glow flash** ≤100 ms; may punch shake |
| Particle look | Bright neon sparks / energy flecks — inherit brick color + white/cyan highlights |
| Pool hard cap | **128** default active; hard max **192** with oldest-eviction |
| Spawn scaling | `count = round(baseCount × vfxIntensity)` after intensity applied |
| Obscuration rule | No particle cluster or flash may hide paddle/ball long enough to cost a rally; if conflict, **cut count/alpha before cutting FPS** |

### Camera shake (D-15…D-19)

| Property | Contract |
|----------|----------|
| Triggers | **Brick destruction** and **life lost** only — never ordinary chip, paddle hit, or power-up catch |
| Feel | Subtle, short, smooth decay; preserve aiming accuracy |
| Cap | Amplitude ≤ **2.5** logical px |
| Impulses @ 1.0 | Destroy **1.2**; life lost **2.0** |
| Decay | ≈ **0.85 per frame @ 60 Hz**; amp &lt; 0.05 → 0 |
| Rapid destroys | Merge overlapping shakes with `max` + hard cap (no additive multi-ball jitter) |
| Intensity | Final offset × `vfxIntensity` → **≈0 at 0.2** |
| Authority | Cosmetic `canvas.translate` inside letterbox save/restore **only** — never mutates simulation, collision, paddle input, or ball trajectories |

### Sonic identity — FX-03 (brief; visual planners need event alignment)

| Property | Contract |
|----------|----------|
| Identity | Modern neon arcade — clean synth blips, punchy impacts, subtle sci-fi textures; **original assets only** |
| Event set | Paddle hit; brick chip; brick break; power-up catch; life lost; win; lose — frame-aligned to impact |
| Brick family | Chip = short softer; break = fuller + brief shimmer (same family) |
| Loudness | Life lost / Win / Lose → Brick break → Paddle hit / Brick chip → Power-up catch |
| Overlap | Pooled voices; per-category limits; reuse oldest at cap — rapid hits overlap, do not cut unbounded |
| UI | **No** audio settings screen; preload before active play; `playsInSilentMode: true` |
