Drop sequence (document order for tests):
1. `roll = nextFloat(rngGameplay, 0)`; if `roll >= 0.2` → no drop
2. `which = nextFloat(rngGameplay, 0)`; if `which < 0.5` → MULTIBALL else EXPAND

Catch (D-10/D-11):
- Each step: for active pickups, `y += PICKUP_FALL_SPEED * dt` (inline `120 * dt`)
- AABB: pickup rect centered at (x,y) size 20×12 vs paddle `[paddleX-halfW, paddleX+halfW] × [paddleY, paddleY+paddleH]`
- On overlap: deactivate pickup; if MULTIBALL → `spawnMultiballFromPaddle(world)`; if EXPAND → `applyOrRefreshExpand(world)`
- If `y > 640` → deactivate

Expand (D-08):
- `EFFECT_TYPE_EXPAND = 1`, duration `effectUntilTick = tick + 1200`
- Refresh: if expand already in effects list, only update `effectUntilTick`
- `derivePaddleWidth`: `paddleW = hasExpand ? 72 * 1.5 : 72` then clamp `paddleX` so half-width in `[0, 360]`

Multiball (D-07/D-14, RESEARCH Q2 lock):
- `freeSlots = maxBalls - activeBallCount`
- `toSpawn = min(2, freeSlots)` — if 0, catch still consumes pickup but spawns nothing
- Spawn from paddle center, speed `SERVE_SPEED = 360`, angles from vertical (−vy): first ball −18° or +18°, second −36° or +36° (assign in order; use + for first free slot index even, − for odd — deterministic)
- Convert deg→vx,vy with y-down: `vx = speed * sin(θ)`, `vy = -speed * cos(θ)`
- Reject/clamp so `|vy|/speed >= MIN_VERTICAL_RATIO` (~cos 62°)
- Activate unused dense slots at `activeBallCount`… and increment `activeBallCount`
- Do not modify existing balls' vx/vy
- Finite guard: skip spawn if non-finite speed
