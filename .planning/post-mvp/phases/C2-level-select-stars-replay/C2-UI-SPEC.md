# Phase C2 — UI Design Contract

> Visual and interaction contract for Level Select + Stars + Replay. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Stack note:** React Native / Expo SDK 57 + Skia — **not** a web component-library app. No shadcn, Tailwind, or CSS framework. Tokens apply to thin React Native shell chrome only. Playfield remains Skia (unchanged).
>
> **Continuity:** Reuse Phase 6 (`06-UI-SPEC.md`) and live `TitleScreen` / `ResultOverlay` / `PauseOverlay` navy/flat SpaceMono language. **Do not** invent purple/cream themes, new brand fonts, glow, blur, or card clusters. CERT/SOAK harnesses bypass Select — not a UI surface for this contract.

## Spacing Scale

Declared values (must be multiples of 4). Used for **React shell chrome** (Select, Results extensions), not virtual playfield physics units.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline star glyph gap; badge padding (inherited) |
| sm | 8px | Compact row inner vertical padding; metric stack gaps |
| md | 16px | Default horizontal padding; button horizontal padding; button stack gap; star row → Best gap |
| lg | 24px | Select content column / Results panel inner padding; screen edge padding |
| xl | 32px | Select heading → list gap; Back control top clearance under safe-area when needed |
| 2xl | 48px | Reserved (inherited Title/Results CTA clearance) |
| 3xl | 64px | Reserved (Title brand rhythm — unchanged) |

**Exceptions:**

| Exception | Value | Reason |
|-----------|-------|--------|
| Touch target minimum | 44×44 px | Back, each Select row, Retry, Next, Menu — same floor as Phase 6 |
| Select row min height | 44 px | Full-width Pressable row; `paddingVertical` 12 + label line ≥ 44 |
| Overlay panel | minWidth 200, maxWidth 320 | Inherit Results / Pause panel bounds |
| Logical playfield | 360×640 vu | Letterbox unchanged; Select is full-screen shell (no playfield) |

**Safe-area:**

- `SelectScreen` and Results overlay lay out **inside** `useSafeAreaInsets` — never under notch / Dynamic Island / home indicator.
- Select root: full-bleed Dominant `#1a1a2e` (same as Title).

## Typography

Shell / chrome only. Exactly **4 sizes**, **2 weights**.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px | 400 | 1.5 (24px) | Select row level labels; Results Score / Best; uncleared/cleared star lines; Select empty-metric absent |
| Label | 14px | 400 | 1.4 (20px) | Locked affordance text; Menu / Back outline labels; New Record badge (inherited) |
| Heading | 20px | 600 | 1.2 (24px) | Select screen title; Results Win / Lose (inherited) |
| Display | 48px | 600 | 1.0 (48px) | Title product name only (unchanged) — **not** used on Select |

**Weights declared (exactly 2):** 400 (regular) + 600 (semibold).  
**Font family:** SpaceMono only. Do not introduce a second family in C2.

**Source:** Live Title / Result styles; `06-UI-SPEC.md` Typography.

## Color

60 / 30 / 10 for **app shell**. Flat solids only — no new neon accents for Select chrome.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#1a1a2e` | Select full-screen background; Title (unchanged); primary CTA label on white buttons |
| Secondary (30%) | `#000000` scrim @ 60%; panel `#12121f` | Results / Pause scrim + panel (unchanged); Select does **not** require a card panel — list sits on Dominant |
| Accent (10%) | `#FFFFFF` | Primary CTA fills; Select heading; unlocked row labels; filled star glyphs; Back/Menu outline borders & labels |
| Muted / locked | `#6B7280` | Locked row label + **Locked** affordance; empty star glyph `☆` |
| Destructive | `#E85D5D` | Lose overlay title only (unchanged) |
| Record highlight | `#F2CC8F` | **New Record** badge fill only (unchanged) |

Accent reserved for:

1. Primary filled CTAs: **Play** (Title), **Retry**, **Next** (white fill + `#1a1a2e` Body label)
2. Select Heading **Levels**; unlocked row Body labels
3. Filled star glyph `★`
4. Outline secondary controls: **Back**, **Menu** (1px `#FFFFFF` border on Dominant/panel fill)

**Never use accent for:** locked rows, empty stars, letterbox, decorative card chrome, toast/preview (forbidden — D-21), CERT/SOAK-only surfaces, purple/indigo/cream themes.

**Secondary CTA (Back / Menu):** outline — Dominant or panel fill, `1px` `#FFFFFF` border, Label `#FFFFFF` — **not** filled white (keeps Retry/Next/Play dominant).

**Source:** `TitleScreen` / `ResultOverlay` / `src/render/colors.ts` (`FIELD_NAVY`, `BRICK_UNBREAKABLE`); C2-CONTEXT styling discretion.

### Title (unchanged except navigation target)

| Element | Copy |
|---------|------|
| Product name | **Neon Brick Breaker** |
| Personal Best | **Best · {n}** |
| Primary CTA | **Play** — navigates to **Select** (not directly Playing) (D-14) |

### Select screen

| Element | Copy |
|---------|------|
| Screen heading | **Levels** |
| Back CTA | **Back** — returns to Title (D-19) |
| Row labels (catalog order) | **Level 01** · **Level 03** · **Level 04** · **Level 05** · **Level 06** — map 1:1 to `PLAYABLE_LEVEL_ORDER` (`level-01`…`level-06`; never show `level-02`) |
| Locked affordance | **Locked** — Label role, muted; **no** stars; **no** Best line |
| Uncleared stars | **☆☆☆** — three empty stars; **no** Best line; **never** **Best · 0** (D-18, D-23) |
| Cleared stars | **★** / **☆** mix totaling three glyphs — filled count = stored stars (1–3); remainder empty |
| Cleared Best | **Best · {n}** — Body; only when row state is **cleared** (`stars` present after ≥1 win) |
| Empty list | N/A — always exactly **5** rows |
| Locked tap feedback | **None** — ignore tap; no toast, no preview, no haptic-required copy (D-21) |
| Error / progress fail | Fail soft: render from in-memory defaults / last good snapshot; **no** error modal on Select |

### Results overlay (evolve)

| Element | Copy |
|---------|------|
| Win heading / body | **Win** / **All clear** (unchanged) |
| Lose heading / body | **Lose** / **Out of lives** (unchanged) |
| Score / Best | **Score · {n}** · **Best · {n}** (unchanged) |
| New Record badge | **New Record** — only when this run set a new best (unchanged) |
| Win stars | Same three-glyph ★/☆ line as Select cleared; show on **win only** (D-10). Use stars from blob returned by `handleRunEnded` (best-stars after merge), not a second async read |
| Lose stars | **Omit entirely** — no star row on lose |
| Primary CTA | **Retry** — always; instant; no confirm |
| Forward CTA | **Next** — win only; visible iff `nextLevelId(cleared)` exists **and** that id is unlocked in returned blob (D-11). **Hidden** (not disabled) on final level (`level-06`) and when next is locked |
| Secondary CTA | **Menu** — returns to **Title** (D-22); not Select |
| Lose actions | **Retry** + **Menu** only — no Next (D-12) |
| Destructive confirmation | **None.** Retry / Next / Menu / Back are instant |

| Control | Label |
|---------|-------|

## Interaction Contract

### Shell navigation (D-17, D-19, D-22)

```
Cold start → Title
Title → Play → Select
Select → Back → Title
Select → tap unlocked row → Playing (required levelId)
Select → tap locked row → ignore (no navigation, no toast)
Playing → Menu (Pause or Results) → Title
Playing → Win | Lose → Results
Results → Retry → reset same level → Playing
Results → Next (when visible) → same PlayingHost, setLevelId(next) only — bake gate arms; never setActive(true) here
Results → Menu → Title
CERT / SOAK → Title ↔ Playing only (bypass Select; not a harness UI screen)
```

### Select list (D-18, D-20, D-21)

| Rule | Contract |
|------|----------|
| Structure | Vertical list of **exactly 5** rows in `PLAYABLE_LEVEL_ORDER` |
| Refresh | Call `getSnapshot()` on **every mount**; no cached progress across visits |
| Row states | `locked` \| `uncleared` \| `cleared` — see Display rules below |
| Locked tap | Ignore — Pressable disabled or `onPress` no-op; no toast/preview/load |
| Unlocked tap | `setShellPhase('playing')` + that `levelId` |
| Playing unmount | Leaving play (Menu/Back path) unmounts PlayingHost (worklets/atlas teardown) |

### Three row display states (normative)

| State | Visible content | Best | Interactive |
|-------|-----------------|------|-------------|
| Locked | Level label (muted) + **Locked** | Hidden | Tap ignored |
| Unlocked, never cleared | Level label + **☆☆☆** | Hidden (never Best · 0) | Tap → play |
| Cleared | Level label + ★/☆ (earned) + **Best · {n}** | Shown | Tap → replay |

**Cleared definition for UI (D-25 / R-30):** `isLevelCleared` — next catalog id unlocked **or** `best.stars ∈ {1,2,3}`. Prefer omit `stars` until first C2 win. Legacy v2 clears (next unlocked, stars omitted) render as **cleared** with **☆☆☆** + Best if score present — not as uncleared.

### Star glyphs (Select + win Results)

| Token | Glyph | Color |
|-------|-------|-------|
| Filled | `★` (U+2605) | `#FFFFFF` |
| Empty | `☆` (U+2606) | `#6B7280` |

- Always render **exactly three** glyphs in a row; gap `xs` (4px) between glyphs.
- Filled count = stored/best stars after win merge (`max(prev, computed)`); Results shows that merged value.
- Formula is lives-based in C2 — UI does not show lives→stars explanation copy.

### Results button order (normative)

**Win (Next visible):** vertical stack, gap `md` (16px):

1. **Retry** — filled primary  
2. **Next** — filled primary (same style as Retry)  
3. **Menu** — outline secondary  

**Win (Next hidden)** / **Lose:**

1. **Retry** — filled primary  
2. **Menu** — outline secondary  

Do **not** render a disabled Next. Omit the control entirely when gated off (D-11).

### Layout sketches

**Select**

```
[ safe-area ]
  [ Back ]                    ← outline, top-leading
  Levels                      ← Heading, centered or leading
  Level 01   ★★☆   Best · 1200   ← cleared example
  Level 03   ☆☆☆                 ← uncleared
  Level 04   Locked              ← locked, muted
  Level 05   Locked
  Level 06   Locked
[ safe-area bottom ]
```

**Results win (with Next)**

```
[ scrim 60% ]
  panel #12121f
  Win / All clear
  Score · N
  Best · N
  ★★☆                         ← win only
  [ New Record? ]
  [ Retry ]
  [ Next ]
  [ Menu ]
```
