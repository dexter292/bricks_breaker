# Security Policy

## Supported versions

Security fixes target the current `main` branch of Neon Brick Breaker / `bricks-breaker`.

## Reporting a vulnerability

Please **do not** open a public issue for security reports.

Use one of:

1. **Email:** [dexter@lkfnb.com](mailto:dexter@lkfnb.com)
2. **GitHub private vulnerability reporting** — [Security advisories](https://github.com/dexter292/bricks_breaker/security/advisories/new) (preferred when enabled on the repository).
3. **GitHub Discussions** — [https://github.com/dexter292/bricks_breaker/discussions](https://github.com/dexter292/bricks_breaker/discussions) for coordinated disclosure when private reporting is unavailable.
