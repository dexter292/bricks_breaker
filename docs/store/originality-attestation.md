# Originality Attestation — Pulse Paddle

## Statement

The MVP build of Pulse Paddle uses **original** gameplay levels, sound effects, and visual assets created for this project. It does **not** include copyrighted third-party game IP, branding, music, level layouts, or asset packs from commercial titles.

## Scope covered

| Asset class | Attestation |
|-------------|-------------|
| Levels (`assets/levels/*.json`) | Hand-authored for this project; not copied from Brick Breaker Maker, Shatter, or other commercial layouts |
| SFX (`assets/sfx/*`) | Project-authored PCM cues; provenance **closed 2026-09-22** in `assets/sfx/README.md` (All rights reserved — app bundle only) |
| Icons / splash / images under `assets/images` | Project art for this app (icon, splash, favicon, Android adaptive layers). Expo template leftovers (`expo-logo.png`, `tabIcons/*`) were removed 2026-09-21. iOS icon points at `assets/images/icon.png` (not `assets/expo.icon` — unused Expo Icon Composer template; safe to delete before store submit). |
| Code | Original project source under this repository |

## Inspiration vs copying

Brick Breaker Maker and Shatter are **feel / aesthetic references** only (classic paddle physics feel; neon arcade look). No assets, branding, music, or level data from those products are included.

## Non-goals

This attestation is an in-repo paperwork artifact for PLT-04 / D-25. It is not a legal opinion and does not replace counsel review before commercial distribution.
